# Variational Estimators for Node Popularity Models

This repository contains the datasets and data-source information used in the real-world network analyses in:

**Variational Estimators for Node Popularity Models**  
Jony Karki, Dongzhou Huang, and Yunpeng Zhao

## Datasets

### MovieLens 100K

The MovieLens 100K dataset contains 100,000 ratings from 943 users on 1,682 movies.

**Source:** [GroupLens MovieLens 100K](https://grouplens.org/datasets/movielens/100k/)

### Political Blogs

The Political Blogs network records hyperlinks between political blogs during the 2004 U.S. presidential election.

**Original reference:** Adamic, L. A. and Glance, N. (2005), *The Political Blogosphere and the 2004 U.S. Election: Divided They Blog.*

**Data source:** [Political Blogs Network](https://public.websites.umich.edu/~mejn/netdata/)

### DBLP

The DBLP network used in the paper is based on the heterogeneous bibliographic network constructed from DBLP data. The analysis uses the subnetwork corresponding to the database and information-retrieval research areas.

**References:** Gao et al. (2009) and Ji et al. (2010).

### British MPs Twitter Network

The British MPs network contains Twitter interactions between Members of Parliament. The analysis uses the retweet network for Conservative and Labour MPs.

**Original reference:** Greene, D. and Cunningham, P. (2013), *Producing a Unified Graph Representation from Multiple Social Network Views.*
